# Epic 3 Retrospective

**Date:** 2026-04-11
**Epic Focus:** Real-time RSVPs, Database Transactions, and Transient UX States

## Epic Summary and Metrics
- **Completed:** 7/7 stories (100%)
- **Themes:** Pessimistic locking, tRPC websockets, complex UI gestures, and optimistic UI feedback.
- **Team Participants:** Project Lead, Alice (Product Owner), Charlie (Senior Dev), Elena (Junior Dev), Dana (QA Engineer), Bob (Scrum Master).

## Successes and Strengths
- **Raw SQL Transaction Locking:** Implemented `SELECT ... FOR UPDATE` directly in Prisma for robust capacity locking, mitigating any race conditions safely.
- **Error Mapping:** Clean conversions of Prisma constraints (e.g., `P2002`) to tRPC `TRPCError` exceptions like `CONFLICT`, providing highly exact frontend feedback via Sonner toasts.
- **Performance:** Micro-component architecture (`<CapacityBar />`) successfully isolated WebSocket re-renders, preventing the entire EventCard from redrawing on tick.
- **UX & Gestures:** The `LongPressButton` sidestepped OS-level context menus effectively, and the transient state machine (`IDLE`, `LOCKING`, `SECURED`, `ERROR`) perfectly met the high-fidelity UX requirements.

## Challenges and Growth Areas
- **Redundant Database Checks:** The codebase initially carried redundant `if (!event)` validations that cluttered the pessimistic lock logic.
- **Layout Shifts (CLS):** Dynamic strings like "Locking..." inside buttons caused minor layout shifts when swapping states until explicitly caught in code review and patched with `w-36` and `whitespace-nowrap`.
- **Review Automation:** Had to fallback to manual adversarial file prompts due to missing subagents, highlighting a reliance on external tooling that requires backup manual contingencies.

## Key Insights and Learnings
- **Isolating Subscriptions:** Putting `api.rsvp.onCapacityChange.useSubscription` explicitly into micro-components is a design pattern we must maintain natively to preserve performance as the app scales.
- **Code Review Rigor:** The `Acceptance Auditor` persona successfully caught UI pixel-shifting discrepancies before they hit production, validating the adversarial multi-layer code review flow.
