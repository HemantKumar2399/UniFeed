## 📖 About UniFeed

UniFeed bridges the gap between chaotic WhatsApp groups and formal university emails. It is a highly-curated, zero-friction event discovery engine where students can scroll through visual teasers, RSVP with a single long-press, and access a digital passport for physical venue check-ins.

### ✨ Key Features
- **Strict Identity Verification**: Locked authentication using `@jecrc.ac.in` Google Domains.
- **Minimalist Feed UX**: Discover events instantly through 15-second ephemeral story bars and visual-first event cards.
- **Pessimistic RSVP Engine**: Guaranteed capacity handling using atomic locking for high-traffic drops.
- **Digital Passport Flow**: Real-time generative QR codes for fast, offline-capable physical venue check-ins.
- **Dashboard Expansion**: Fully separate, complex 3-column data grid environment for high-powered Event Organizers.

## 🛠 Tech Stack

Built to scale, using the [T3 Stack Architecture](https://create.t3.gg/):

| Layer | Technology | Purpose |
| ------ | ----------- | ------- |
| **Framework** | Next.js 15 (App Router) | Server-Side Rendering (SSR) & Routing |
| **Styles** | Tailwind CSS + shadcn/ui | Radix-based unstyled accessible components |
| **Database** | PostgreSQL | Relational ACID-compliant state |
| **ORM** | Prisma | Strongly typed database client |
| **API** | tRPC | End-to-end typesafe API without GraphQL/REST boilerplate |
| **Auth** | NextAuth.js (v5) | Google Provider + Secure JWTs |

## 🚀 Quick Start (Local Development)

We value developer experience (DX). To get this mammoth project running on your local machine instantly, we have a unified setup script.

### 1. Unified Setup
From your terminal, run our onboarding script (this automatically handles `npm install`, sets up your `.env`, and pushes Prisma state):
```bash
./scripts/setup-local.sh
```

### 2. Enter Environment Credentials
If you are starting from scratch, open the `.env` file generated by the script and insert your local or cloud generic Postgres Database URL. Example:
```env
POSTGRES_URL="postgres://postgres:password@localhost:5432/unifeed"
```

### 3. Blast Off
Once your database URL is set, boot up the environment:
```bash
npm run dev
```
